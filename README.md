# 과정 중심 과제 제출·피드백 웹앱 (Apps Script)

보고서를 한 번에 받지 않고 **단계마다 받아 피드백을 주는** 웹앱입니다.
학생은 단계별로 과제를 내고, 교사는 구글 시트에서 제출물을 보며 **예상 점수와 피드백**을 정리합니다.
며칠 뒤 학생이 웹앱에 다시 들어오면 **PDF 피드백 문서**를 바로 볼 수 있습니다.

주소는 하나입니다. 학생은 웹앱 주소로 들어와 제출과 피드백 확인을 모두 하고, 교사는 같은 주소 끝에 `?page=admin`을 붙여 관리 화면으로 들어갑니다. 구글 설문지는 쓰지 않습니다.

```
학생: 단계 제출 ──▶ 제출 완료 메일 자동 발송
                         │
교사(관리 화면): AI 초안 ─▶ 읽고 고치기 ─▶ 확정 ─▶ PDF 만들기 ─▶ 공개 체크 + 공개일
                                                               │
학생: (공개일 이후) 웹앱에서 학번·이름 입력 ─▶ 진행 상황·예상 점수 변화·PDF 보기
      + 피드백 도착 메일 (매일 아침 자동)
```

## 무엇이 달라졌나 (PRD v2 대비)

| 구분 | 내용 |
|---|---|
| 단계 제출 | `단계` 시트에 주제 정하기 → 자료 조사·개요 → 초안 → 최종 보고서처럼 단계를 정합니다. 단계마다 마감, 열림, 늦은 제출 허용, 제출 방식(파일/글/둘 다)을 따로 둡니다. |
| 과정 기록 | 학생은 제출할 때마다 **"이번 단계에서 한 일"**(필수)과 **"어려웠던 점·질문"**을 적습니다. 결과물만이 아니라 과정을 보고 피드백할 수 있습니다. |
| 예상 점수 | 단계마다 "지금 상태 그대로 최종 제출하면 루브릭으로 몇 점일지"를 시트에 적습니다. 학생 화면에 **단계별 예상 점수 변화 막대**가 나옵니다. |
| AI 초안 (선택) | Claude가 제출 파일(PDF·docx·구글 문서·이미지)과 과정 기록, **이전 단계 피드백**을 함께 읽고 예상 점수·잘한 점·보완할 점·다음 단계까지 할 일 초안을 시트에 채웁니다. 교사가 고친 뒤 확정합니다. |
| PDF 피드백 | 제출 정보, 과정 기록, 예상 점수표, 단계별 성장 기록, 교사 의견을 담은 PDF를 만듭니다. |
| 며칠 뒤 공개 | `공개` 체크 + `공개일`을 정하면 그날부터 학생 화면에 나타납니다. |
| PDF 보기 | 학생은 웹앱 안에서 PDF를 봅니다 (pdf.js). **PDF 공유 설정을 바꾸지 않으므로** 링크가 퍼질 걱정이 없습니다. |
| 메일 | 제출 즉시 **제출 완료 메일**, 공개일이 되면 **피드백 도착 메일**을 보냅니다. |

## 파일 구성

```
src/
  appsscript.json   매니페스트 (웹앱: 나로 실행, 모든 사용자 접근 / Drive 고급 서비스)
  Config.gs         시트 이름, 열 이름, 공통 도우미
  Setup.gs          시트 메뉴, 처음 설정, 트리거, onEdit(합계 자동 계산)
  WebApp.gs         doGet, 제출(submitAssignment), 조회(lookup), PDF 전달(getFeedbackPdf)
  Mail.gs           제출 완료 메일, 피드백 도착 메일
  Ai.gs             Claude API로 예상 점수·피드백 초안 만들기
  Feedback.gs       확정, PDF 만들기, 공개
  AdminApi.gs       관리 화면 서버 함수 (로그인, 현황, 피드백 저장, 설정, 명단)
  Index.html        학생 화면
  Admin.html        관리 화면
  Stylesheet.html   노랑·데님 테마 (공통)
  AdminStyle.html   관리 화면 추가 스타일
  JavaScript.html   학생 화면 동작
  AdminJs.html      관리 화면 동작
  PdfViewer.html    PDF 보기 (학생·교사 공통, pdf.js)
scripts/deploy-gws.sh   gws CLI로 시트·스크립트 만들고 배포
```

## 설치

### 방법 1. gws CLI로 한 번에

처음 한 번만 준비합니다.

```bash
npm install -g @googleworkspace/cli        # gws 0.22 이상
gws auth setup --login                     # gcloud가 있을 때. 없으면 아래 '수동 OAuth 설정' 링크 참고
gws auth login -s script,sheets,drive      # Apps Script 권한을 꼭 함께 받습니다
```

- [Apps Script 설정](https://script.google.com/home/usersettings)에서 **Google Apps Script API**를 켭니다.
- gcloud 없이 준비하려면 [gws 수동 OAuth 설정](https://github.com/googleworkspace/cli#manual-oauth-setup-google-cloud-console)을 따릅니다. 이때 Cloud 프로젝트에서 Apps Script API, Sheets API, Drive API를 사용으로 바꿉니다.

그다음 실행합니다.

```bash
./scripts/deploy-gws.sh check                      # 로그인·권한·API가 준비됐는지 점검
./scripts/deploy-gws.sh init "인간과 심리 1차 과제"   # 시트 + 스크립트 + 코드 + 첫 배포
./scripts/deploy-gws.sh deploy "피드백 화면 수정"      # 코드를 고친 뒤: 같은 주소로 새 버전 배포
./scripts/deploy-gws.sh status                     # 저장된 ID와 주소 보기
```

- `init`이 중간에 실패하면 안내대로 고친 뒤 같은 명령을 다시 실행하세요. 이미 만든 시트와 스크립트는 다시 만들지 않고 이어서 합니다.
- 이미 만든 시트에 붙이려면 `init --sheet 시트ID`를 씁니다.
- 실패하면 원인(로그인, 권한, API 꺼짐, 학교 관리자 차단)을 한국어로 알려 줍니다.
- `init`이 끝나면 **시트를 열어 `📮 과제 피드백 > ① 처음 설정`을 꼭 한 번 실행**하세요. 그 전에는 웹앱 주소를 열면 권한 오류가 납니다.

### 방법 2. 직접 붙여 넣기

1. 새 구글 시트 → 확장 프로그램 → Apps Script.
2. `src/`의 파일을 같은 이름으로 만들고 내용을 붙여 넣습니다. (`appsscript.json`은 프로젝트 설정에서 "매니페스트 파일 표시"를 켜야 보입니다.)
3. 왼쪽 **서비스 +** 에서 **Drive API**를 추가합니다.
4. 배포 → 새 배포 → 웹 앱 (실행: 나, 액세스: 모든 사용자).

### 처음 설정

1. 시트를 새로 고치면 **📮 과제 피드백** 메뉴가 생깁니다. **① 처음 설정**을 누르고 권한을 허용합니다. 이때 **관리자 비밀번호**도 정합니다. (비밀번호는 시트 주인만 처음 정할 수 있습니다.)
2. 웹앱으로 배포합니다 (실행: 나, 액세스: 모든 사용자).
3. 이제부터는 `웹앱 주소?page=admin` 관리 화면에서 모두 합니다. 학생 화면 맨 아래 "선생님" 링크로도 들어갈 수 있습니다.

## 관리 화면

| 탭 | 하는 일 |
|---|---|
| 📋 제출 현황 | 단계별 제출 수와 피드백 할 것, 공개된 수를 한눈에 봅니다. 단계·상태·이름으로 거르고, 명단이 있으면 아직 내지 않은 학생도 보입니다. 여러 명을 골라 AI 초안, 확정, PDF 만들기, 공개(공개일 지정), 공개 취소를 한 번에 합니다. 도착 메일도 여기서 보냅니다. |
| ✏️ 피드백 작성 | 왼쪽에 제출 내용(과정 기록, 질문, 본문, 파일 미리 보기)과 이전 단계에서 준 할 일이, 오른쪽에 루브릭 점수 칸과 의견 칸이 나옵니다. 점수는 0부터 배점까지만 들어가고 합계가 바로 바뀝니다. AI 초안 → 고치기 → 저장하고 확정 → PDF 만들기 → 공개 순서로 쓰고, "다음 ▶"으로 다음 학생에게 넘어갑니다. |
| ⚙️ 과제 설정 | 과목·과제 이름, 안내문, 파일 조건, 메일 사용 여부와 제목, AI 모델을 고칩니다. 단계(이름, 학생 안내, 피드백 초점, 마감, 제출 방식, 열림, 늦은 제출)와 루브릭(항목, 배점, 상·중·하)을 추가·삭제·순서 바꾸기 할 수 있습니다. |
| 👥 명단·도구 | 명단을 붙여 넣어 저장하고, 매일 아침 도착 메일 자동 발송을 켜고, AI API 키와 관리자 비밀번호를 바꿉니다. |

여러 명을 한꺼번에 처리할 때는 실행 시간 제한(6분)에 걸리지 않게 나누어 실행하며, 화면이 남은 일을 이어서 요청합니다.

시트 메뉴도 그대로 남아 있어, 시트에서 직접 고치고 싶을 때 쓸 수 있습니다. 메뉴 기능은 시트 안에서만 실행되고 웹앱에서는 실행되지 않습니다.

## 시트 구조

| 시트 | 주요 열 |
|---|---|
| 설정 | 키, 값, 설명 (과목, 과제명, 메일 사용 여부·제목, AI 모델, 폴더 ID 등) |
| 단계 | 단계ID, 단계명, 학생 안내, 피드백 초점, 제출 방식, 마감일시, 열림, 마감 후 제출 허용 |
| 루브릭 | 평가 항목, 배점, 상, 중, 하 — **최종 결과물** 기준표 |
| 명단 | 학번, 이름, 이메일 (명단 이메일이 학생이 적은 이메일보다 우선) |
| 제출 | 접수번호, 제출시각, 학번, 이름, 이메일, 단계, 한 일, 질문, 본문, 파일, 제출차수, 완료메일 |
| 피드백 | 접수번호 … `예상:항목` 열들, 예상 합계, 잘한 점, 보완할 점, 다음 단계까지 할 일, 한 줄 총평, 상태, 공개일, 공개, PDF … |

루브릭 항목을 바꾸면 **루브릭 바꾼 뒤: 피드백 시트 점수 열 맞추기**를 누르세요.

## 보안과 개인정보

- 학번+이름으로 본인을 확인합니다. 같은 학번으로 5번 틀리면 10분 동안 조회를 막습니다.
- 관리 화면은 비밀번호(스크립트 속성에 소금값을 더한 해시로 저장)로 들어가며, 로그인은 6시간 유지됩니다. 비밀번호를 10번 틀리면 10분 동안 막습니다.
- 공개 전에는 점수·의견·PDF가 서버에서 아예 내려가지 않습니다.
- 제출 파일과 PDF는 교사 드라이브에 비공개로 있습니다. 학생은 본인 확인을 거쳐 웹앱 안에서만 PDF를 봅니다.
- 학생 입력은 화면과 메일에 넣을 때 모두 HTML 특수문자를 바꿉니다.
- AI 초안을 쓰면 제출물이 Anthropic API로 전송됩니다. 학교 지침을 확인하고, 학생 안내문에 알려 주세요.

## 제약

- 한 번 실행은 6분, 업로드는 10MB 이하를 권장합니다. Gmail 하루 발송량에 한도가 있습니다.
- 한글(hwp) 파일은 AI가 읽지 못합니다. AI 초안을 쓰려면 PDF로 내도록 안내하세요.
- 코드를 고친 뒤에는 새 버전으로 배포해야 학생 화면에 반영됩니다 (`deploy-gws.sh deploy`).
